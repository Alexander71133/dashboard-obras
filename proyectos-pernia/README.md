# Proyectos Pernia

Tablero estático de Inversora Macroandes para GitHub Pages. Los datos y adjuntos se generan desde la carpeta de Dropbox configurada en `generar_dashboard.py`.

## Actualizar el tablero

1. Actualizar el libro `Tablero Control Pernia.xlsx` o sus carpetas de documentos en Dropbox.
2. Desde esta carpeta, ejecutar `python generar_dashboard.py`.
3. Publicar los cambios del repositorio `dashboard-obras` en `main`.

El tablero y todos los archivos de `documentos/` se sirven públicamente con GitHub Pages. No incluir archivos que deban permanecer privados.
